# 🧠 Smart Flashcard Generator

Turn raw study material — notes, textbook chapters, PDFs — into ready-to-study flashcards and quiz questions, automatically generated by an LLM.

Feed it a chapter. Get back structured Q&A pairs or multiple-choice questions, tagged by difficulty and topic, ready for flashcard review, quiz mode, or export to Anki.

---

## ✨ Features

- 📄 **Flexible ingestion** — paste notes, or upload PDF/DOCX/TXT files
- ✂️ **Smart chunking** — splits material by heading, section, or token count so context isn't lost
- 🔍 **Concept extraction** — LLM pulls out key facts, definitions, and relationships per chunk
- ❓ **Question generation** — produces flashcards (front/back) or MCQs with plausible distractors
- 🏷️ **Auto-tagging** — classifies questions by difficulty (easy/medium/hard) and type (definition, application, comparison)
- 🗂️ **Deck organization** — groups generated cards into topic-based decks
- 📤 **Export options** — Anki (`.apkg`), CSV, or JSON
- 🔁 **Spaced repetition** — Leitner-system tracking that resurfaces cards you get wrong more often
- ✅ **Validation** — filters out duplicate or malformed questions before they hit your deck

---

## 🏗️ How It Works

```
Notes/PDF → loader.py → chunker.py (sections)
                              ↓
                  concept_extractor.py (key facts per section)
                              ↓
                  question_generator.py (Q&A pairs / MCQs)
                              ↓
                  card_model.py → deck_builder.py (organized deck)
                              ↓
              study_mode/ (flashcard flip or quiz session)
                              ↓
              spaced_repetition.py (tracks weak cards, resurfaces them)
```

1. **Input** — Upload your notes, PDF, or textbook chapter
2. **Chunk** — Material is split into digestible sections
3. **Extract** — The LLM identifies key facts and concepts per chunk
4. **Generate** — Flashcards or MCQs are created from those concepts
5. **Tag** — Each question is classified by difficulty and type
6. **Study** — Review via flip-card UI or quiz mode
7. **Reinforce** *(optional)* — Weak cards resurface more often via spaced repetition

## 🚀 Getting Started

### Prerequisites

- Python 3.10+
- An Anthropic (or OpenAI) API key

### Installation

```bash
git clone https://github.com/your-username/flashcard-generator.git
cd flashcard-generator
python -m venv venv
source venv/bin/activate    # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### Configuration

Copy the example environment file and add your API key:

```bash
cp .env.example .env
```

```env
ANTHROPIC_API_KEY=your_api_key_here
CHUNK_SIZE=1000
QUESTIONS_PER_CHUNK=5
DEFAULT_DIFFICULTY_MIX=easy:medium:hard=2:2:1
```

### Run

```bash
./run.sh
# or directly:
streamlit run app/main.py
```

## 🧩 Usage

1. Launch the app and upload a file (or paste notes directly)
2. Choose output type: **flashcards** or **multiple-choice quiz**
3. Set question count and difficulty mix (optional)
4. Click **Generate** — review the auto-created cards, edit or discard any that look off
5. Study in **Flashcard mode** (flip cards) or **Quiz mode** (scored MCQs)
6. Export your deck to Anki, CSV, or JSON whenever you're ready

## 🗃️ Card Schema

Every generated card follows a consistent structure regardless of type:

```json
{
  "id": "card_0001",
  "type": "flashcard | mcq",
  "prompt": "What is the powerhouse of the cell?",
  "answer": "The mitochondrion",
  "distractors": ["The nucleus", "The ribosome", "The Golgi apparatus"],
  "difficulty": "easy | medium | hard",
  "question_type": "definition | application | comparison",
  "topic": "Cell Biology",
  "source_chunk_id": "chunk_012"
}
```

`distractors` is only populated for `mcq` type cards.

---

## 🔁 Spaced Repetition

Uses a simple **Leitner system**:

- Cards start in box 1
- Correct answers move a card up a box (reviewed less often)
- Incorrect answers send a card back to box 1 (reviewed again soon)
- Study sessions prioritize cards due for review based on their current box
